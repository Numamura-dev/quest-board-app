# 操作マニュアル

このマニュアルは、現在のアプリケーションに実装されている画面だけを対象にした利用者向け手順です。スクリーンショットはローカル環境で `pnpm db:push` と `pnpm --filter backend seed` を実行し、フロントエンドとバックエンドを起動したうえで `pnpm docs:screenshots` から生成します。

## 事前条件

- フロントエンドが `http://localhost:3000`、バックエンド API が `http://localhost:3001` で起動していること。
- MySQL に Prisma schema と seed データが反映されていること。
- `.env.local` と E2E 用 `.env` を example から作成し、必要な実値を設定していること。

```bash
cp apps/frontend/.env.local.example apps/frontend/.env.local
cp apps/backend/.env.local.example apps/backend/.env.local
cp apps/e2e/.env.example apps/e2e/.env
```

- Google アカウントでログインできること。
  - スクリーンショット撮影用の E2E テストは、バックエンドのテスト用トークン発行エンドポイント（`/api/test/token`）を使って認証をバイパスする。

## 画面一覧

| 画面 | URL | 主な用途 |
| --- | --- | --- |
| ホーム | `/` | ログイン前の入口、ログイン後のクエスト一覧 |
| ログイン | `/login` | Google アカウントでのログイン |
| クエスト一覧 | `/quests` | クエスト検索、絞り込み、参加 |
| クエスト詳細 | `/quests/:id` | 完了済みクエストの詳細とレビュー確認 |
| マイページ | `/mypage` | プロフィール、参加履歴、通知確認 |
| 管理者ダッシュボード | `/admin/dashboard` | 指標、クエスト管理、ユーザー管理 |

## ログイン前ホーム

<img alt="ログイン前ホーム" :src="'/manual/home-logged-out.png'">

### 目的

アプリの入口からログインに進みます。

### 操作手順

1. `/` を開きます。
2. 「ログイン」を選択します。

### 確認できること

ログイン前はクエスト一覧ではなく、ログインへの導線が表示されます。

### 注意点

ログイン状態が残っている場合は、ホームにクエスト一覧が表示されます。

## ログインする

<img alt="ログイン画面" :src="'/manual/login.png'">

### 目的

Google アカウントでアプリを利用できる状態にします。

### 操作手順

1. `/login` を開きます。
2. 「Google でログイン」ボタンを押します。
3. Google のアカウント選択画面で利用するアカウントを選びます。
4. 認証が完了するとホームに移動します。

### 確認できること

ログイン後はホームまたは `/quests` でクエスト一覧を確認できます。

### 注意点

初回ログイン時はバックエンド側でユーザーが自動登録されます。以降は同じ Google アカウントでログインすることで既存のデータが引き継がれます。

## クエストを探す

<img alt="クエスト一覧" :src="'/manual/quests-list.png'">

### 目的

参加できるクエスト、進行中のクエスト、完了済みクエストを一覧で確認します。

### 操作手順

1. ログイン後に `/quests` を開きます。
2. カードのタイトル、説明、タグ、報酬、参加者数、期限を確認します。
3. 募集中のクエストでは「クエストに参加する」を押して参加確認に進みます。
4. 完了済みのクエストでは「レビューを見る」または「レビューを投稿する」を押して詳細へ進みます。

### 確認できること

クエストのステータス、難易度、参加状況、報酬がカード単位で確認できます。

### 注意点

下書き、承認待ち、停止中など一部ステータスのクエストは一般ユーザー一覧に表示されません。

## 検索と絞り込み

<img alt="検索と絞り込み後のクエスト一覧" :src="'/manual/quests-filtered.png'">

### 目的

キーワード、ステータス、公開開始日でクエストを絞り込みます。

### 操作手順

1. 検索欄にタイトル、本文、タグに含まれるキーワードを入力します。
2. ステータスのプルダウンから「募集中」「進行中」「完了済み」などを選択します。
3. 必要に応じて「公開開始日 From」「公開開始日 To」を入力します。
4. 条件を解除する場合は「フィルタをリセット」を押します。

### 確認できること

入力中のキーワードに応じて候補と検索状態が表示されます。

### 注意点

検索条件に一致しない場合は「クエストが見つかりません」と表示されます。

## クエストに参加する

<img alt="参加確認ダイアログ" :src="'/manual/quest-join-dialog.png'">

### 目的

募集中のクエストに参加します。

### 操作手順

1. クエスト一覧で「クエストに参加する」を押します。
2. ダイアログでタイトル、説明、難易度、参加者数を確認します。
3. 参加する場合は「参加する」を押します。
4. 取り消す場合は「キャンセル」を押します。

### 確認できること

参加が成功すると「クエストに参加しました！」のアラートが表示されます。

### 注意点

未ログイン、満員、重複参加などの場合は参加できないことがあります。

## レビューを見る・投稿する

<img alt="クエスト詳細とレビュー" :src="'/manual/quest-detail-review.png'">

### 目的

完了済みクエストの詳細、レビュー一覧、レビュー投稿欄を確認します。

### 操作手順

1. クエスト一覧で完了済みクエストの「レビューを見る」を押します。
2. クエスト詳細とレビュー平均、レビュー件数を確認します。
3. 参加済みで未投稿の場合は「レビューを投稿する」から投稿フォームを開きます。
4. 評価とコメントを入力して送信します。

### 確認できること

投稿済みレビューの評価、投稿者、コメント、投稿日を確認できます。

### 注意点

完了していないクエストではレビュー画面ではなく「レビューできません」と表示されます。

## マイページを見る

<img alt="マイページ" :src="'/manual/mypage.png'">

### 目的

自分のプロフィール、クエスト履歴、通知を確認します。

### 操作手順

1. ログイン後に `/mypage` を開きます。
2. プロフィール欄で名前とメールアドレスを確認します。
3. クエスト履歴のタブで「募集中」「完了済み」「応募中」を切り替えます。
4. 通知一覧で自分宛てのお知らせを確認します。

### 確認できること

ログイン中ユーザーに紐づく参加履歴と通知が表示されます。

### 注意点

履歴がないタブでは「該当するクエストがありません」と表示されます。

## ログアウトする

### 目的

現在のログイン状態を終了します。

### 操作手順

1. ヘッダーのログアウト操作を選択します。
2. ログイン前ホームに戻ったことを確認します。

### 確認できること

ログアウト後はログイン前ホームが表示され、クエスト一覧やマイページは認証が必要な状態になります。

### 注意点

共有端末では、作業終了後にブラウザの保存情報も必要に応じて削除してください。

## 管理画面を開く

<img alt="管理者ダッシュボード" :src="'/manual/admin-dashboard.png'">

### 目的

管理者としてクエストとユーザーを管理します。

### 操作手順

1. 管理者アカウントでログインします。
2. `/admin/dashboard` を開きます。
3. 上部タブから「ダッシュボード」「クエスト管理」「ユーザー管理」を切り替えます。

### 確認できること

総クエスト数、承認待ち、完了クエスト、最近のアクティビティを確認できます。

### 注意点

一般ユーザーで開くと、管理者権限が必要な画面として扱われます。

## クエストを管理する

<img alt="管理者のクエスト管理" :src="'/manual/admin-quests.png'">

### 目的

管理者としてクエストの検索、作成、編集、削除、復元、ステータス変更を行います。

### 操作手順

1. 管理画面で「クエスト管理」タブを開きます。
2. 検索欄にキーワードを入力します。
3. ステータスのプルダウンで「承認待ち」「公開中」「完了」「下書き」「進行中」「停止中」「削除済み」を選択します。
4. 新規作成する場合は「新しいクエストを作成」を押します。
5. クエスト行を選択し、詳細モーダルから承認、却下、公開、非公開、進行中、完了、編集、削除、復元を実行します。

### 確認できること

条件に一致するクエスト件数、ステータス、参加者数、期限を確認できます。

### 注意点

削除は論理削除です。削除済みフィルタから対象を開くと復元できます。

## ユーザーを管理する

<img alt="管理者のユーザー管理" :src="'/manual/admin-users.png'">

### 目的

登録ユーザーの一覧確認、ロール変更、削除を行います。

### 操作手順

1. 管理画面で「ユーザー管理」タブを開きます。
2. ユーザー名、メールアドレス、現在のロールを確認します。
3. ロールのプルダウンで「一般ユーザー」または「管理者」を選択します。
4. 削除する場合は「削除」を押し、確認ダイアログで確定します。

### 確認できること

ロール変更が成功すると、画面上に変更完了のメッセージが表示されます。

### 注意点

ユーザー削除はアプリ内のデータのみ削除されます。Google アカウント自体は影響を受けません。
